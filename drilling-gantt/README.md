# Визуализация графика бурения

Скрипт превращает книгу «График строительства скважин» (.xlsb, .xlsx, .xlsm) в одну
HTML-страницу с интерактивной диаграммой Ганта. Страница открывается в любом браузере
без установки.

```bash
pip install -r requirements.txt
python3 build_gantt.py "График строительства скважин.xlsb" -o out/grafik.html
```

## Что на странице

- **По бригадам** — дорожка на каждую буровую бригаду: монтаж и передвижка (ВМР),
  бурение, консервация и простой. Над дорожкой скобками отмечены кусты, у названия
  бригады показано, чем она занята сегодня.
- **Цикл по скважинам** — строка на каждую скважину: ВМР, бурение, заканчивание
  (КРС, ГРП, освоение, ГКИ), обустройство и ВНР, ромб — ввод в эксплуатацию.
- Светлая заливка — в столбце «Наличие финансирования» стоит «не утвержден»
  (переключается флажком).
- Сводка по годам: начатые и оконченные скважины, проходка, сутки бурения, ВМР
  и простоя, число вводов.
- Таблица скважин и фильтр по бригаде.

## Что проверяется

- окончание этапа раньше начала и расхождение дат со столбцом «сут»;
- ввод в эксплуатацию раньше окончания бурения или освоения/ГРП;
- ГРП, начатый до окончания бурения;
- статус «Бурение» при прошедшей плановой дате окончания и похожие несоответствия;
- пересечение работ одной бригады;
- плановые скважины, которые не попали в годовые столбцы «Проходка Всего за …г.»
  или попали туда с другой проходкой;
- один номер решения ИК с разными датами;
- устаревший лист «Данные», по которому макрос строит «График визуализация».

Столбцы ищутся по заголовкам строки с «Куст», «Скважина» и «Бурение», поэтому
вставка новых столбцов в лист не ломает разбор.

## Данные в репозиторий не кладём

Репозиторий публичный. Книги графиков и собранные HTML-страницы содержат рабочие
данные, поэтому они перечислены в `.gitignore`; собирайте страницы в папку `out/`.
